# ⚡ VeloVPN — All-in-One Ultimate Personal Edition (100% Free)

Cross-platform **Windows `.exe` + Android `.apk`** personal WireGuard VPN app with **$0 server cost**.

## Features Included
- **⚡ Auto Free Turbo & Gaming UDP Tunnel:** Generates Curve25519 keys on your device and registers a free personal WireGuard profile automatically.
- **📊 Live Ping, Jitter & Speed Meter:** Real-time download/upload speed, session data, and server ms ping tester.
- **🛡️ Built-in DNS Ad, Tracker & Malware Blocker:** Switch between `1.1.1.1` Gaming DNS, `AdGuard` AdBlock DNS, and `1.1.1.2` Malware Shield.
- **🔥 Firewall Port Bypass:** One-tap port switch (`UDP 2408`, `UDP 500`, `UDP 4500`).
- **🌍 Country `.conf` Manager:** Paste free country `.conf` profiles (e.g., Proton VPN Free USA / Japan / NL).
- **📱 Android App Split-Tunneling + Strict Kill Switch.**
